# Map files

The threat maps draw from the two files of this folder. The backend serves them to signed-in users
under `/api/maps/`, and the build copies them next to the bundle.

## world.pmtiles

The base map: vector tiles from zoom 0 to 5 in the [PMTiles](https://docs.protomaps.com/pmtiles/)
format, read by byte ranges.

- Source: the OpenCTI repository (Apache-2.0), file
  `opencti-platform/opencti-graphql/static/maps/world.pmtiles` at commit
  `f519cafd3f064915a742e60ec8d7327ac1aad91d`.
- Data: a [Protomaps](https://protomaps.com/) build of [OpenStreetMap](https://www.openstreetmap.org/)
  data, under the [Open Database License (ODbL)](https://www.openstreetmap.org/copyright). The licence
  requires the attribution, which the map shows as "© OpenStreetMap", linked to the copyright page.

To rebuild one, extract the low zooms of a daily planet build with the
[go-pmtiles](https://github.com/protomaps/go-pmtiles) command line. It reads the planet by HTTP
ranges and never downloads it whole:

```bash
pmtiles extract https://build.protomaps.com/YYYYMMDD.pmtiles world.pmtiles --maxzoom=6
```

The maps frame at zoom 5 at most, so tiles beyond zoom 6 only add weight.

## countries.json

The country polygons the maps colour: a GeoJSON `FeatureCollection` whose features carry `ISO3`,
`ISO2` (empty when the country has no ISO alpha-2 code) and `NAME`. A targeted country is drawn
with every polygon whose `ISO2` matches its code.

- Data: [Natural Earth](https://www.naturalearthdata.com/) 1:50m admin-0 countries, release 5.1.2,
  in the public domain.
- Generated by `back/scripts/generate-countries-geojson.ts`, which downloads the pinned release (or
  reads a local copy given as its argument) and rounds the coordinates to three decimals:

```bash
cd back && yarn tsx scripts/generate-countries-geojson.ts
```
